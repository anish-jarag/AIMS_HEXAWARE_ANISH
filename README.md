## Tech Stack
This project is built using **Spring Boot** for the backend and **React** for the frontend. The backend uses **Spring Security (JWT)**, **Spring Data JPA (Hibernate)**, and **MySQL** as the database, with **Maven** as the build tool. The frontend is developed with **React 18**, **React Router**, and **Axios** for API communication, styled with **Tailwind CSS / Bootstrap**.

## How to Run
To start the backend, navigate to the `backend/` folder, configure your MySQL database in `application.properties`, and run `mvn spring-boot:run`. The server will start on **http://localhost:8080**. For the frontend, go to the `frontend/` folder, run `npm install` followed by `npm start`, and the app will be available at **http://localhost:3000**. Ensure both backend and frontend are running simultaneously for full functionality.
